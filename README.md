# 6ixNetworks ✦

a whole second internet in one site — search, games, movies, chat n an ai, all running thru one tunnel so it works where the normal web doesn't.

**live:** [usareme.site](https://usareme.site) — every `*.usareme.site` door works too


## what's inside

- **search** — real browser-style tabs on an ultraviolet + wisp engine
- **games** — an 8,000+ game catalog, a built-in n64 emulator library, game requests with votes
- **6ixflix** — movies n shows across a stack of sources, direct by default
- **the vault** — 63,000+ public-domain films n shows as real files
- **apk vault** — 4,900+ open-source android apps (f-droid) as real .apk files
- **6ixtube** — youtube, streamed thru ur own connection
- **6ixchat** — accounts, friends, dms, voice + video calls that ride along on every page
- **six ai** — a gemini-powered ai: chat, drawing, homework help, n a game forge that builds a playable game from one sentence
- **plus** — daily news briefs, a confession wall, people, requests, a focus space

## run ur own

one node server does the whole thing:

```bash
git clone https://github.com/daisupply/6ixnetworks
cd 6ixnetworks
npm install
node server.js   # http://localhost:8080
```

optional env vars unlock more: gemini keys (six's brain), upstash (accounts + chat persistence), resend (password-reset mail).
